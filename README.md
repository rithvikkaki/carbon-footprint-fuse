# EcoFuse - Carbon Footprint Hub

EcoFuse is a decentralized sustainability platform that turns personal and enterprise carbon footprint accounting into verifiable, liquid Carbon Credit Tokens (CCT).

## Features
- **Multi-Step Footprint Calculator**: Sector-specific activity accounting (Transportation, Home Energy, Waste, Diet) with localized country grid coefficients.
- **On-Chain CCT Tokenomics**: Verified carbon reductions automatically earn ERC-20 CCT credits into your connected Web3 wallet.
- **Decentralized Spot Marketplace**: Buy and sell carbon credits via transparent order books.
- **Eco Rewards Redemption**: Exchange CCT for electric charging passes, tree planting certificates, and sustainable lifestyle vouchers.
- **Corporate ESG Collaborations**: Review detailed corporate audits and form cross-verified climate partnerships.
- **MetaMask Web3 Integration**: Seamless wallet connection and smart contract event synchronization.

## Tech Stack
- React 18 + TypeScript + Vite
- Tailwind CSS + Lucide React
- Radix UI Primitives (shadcn/ui style system)
- React Router DOM v6

## Running Locally

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
